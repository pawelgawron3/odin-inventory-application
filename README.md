# TeaStock 🍵

TeaStock is a simple inventory management application for a tea shop, built with Node.js, Express and PostgreSQL. It allows users to manage teas and their origins through a clean web interface while keeping data and relationships consistent at the database level.

---

## 🚀 Features

- View all teas in the inventory
- View detailed information about individual teas
- Add, edit and delete teas
- Assign teas to categories and origins
- View teas belonging to a specific category
- Add and delete tea origins
- Prevent deleting origins that are currently used by teas
- Prevent duplicate origins using a database constraint
- Handle missing resources with a custom 404 page
- Responsive and minimal UI
